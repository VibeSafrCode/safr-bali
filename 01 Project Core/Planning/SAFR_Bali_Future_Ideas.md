## Platform Expansion: Website, Mini App, Mobile App

### Website

Будущий сайт должен стать публичной витриной SAFR Bali.

Потенциальные разделы:

- визы
- жильё
- тревел-ассистент
- консультации
- недвижимость
- блог / SEO-страницы
- формы заявок
- контакты
- переход в Telegram-бота

Сайт должен подключаться к тому же backend, что и Telegram-бот.

### Telegram Mini App

Mini App — следующий логичный слой после Telegram-бота.

Потенциальные функции:

- личный кабинет
- SAFR Points
- реферальная сеть
- карточки виз
- каталог вилл
- статусы заявок
- купленные услуги
- загрузка документов
- оплата

Mini App должен использовать Telegram init data для проверки пользователя.

### Mobile App Potential

В будущем архитектура должна позволить выйти в мобильное приложение.

Потенциальные функции:

- единый аккаунт пользователя

- документы
- напоминания
- push-уведомления
- реферальная сеть
- бонусы SAFR Points
- каталог объектов

Важно: backend должен быть не только “под Telegram”, а как основа для разных каналов:

- Telegram Bot
- Telegram Mini App
- Website
- VK API

## Voice Messages And Future STT

Current MVP:

- голосовые сообщения должны ходить в обе стороны как голосовые;
- клиент может отправить голосовое админу;
- админ может ответить клиенту голосовым;
- расшифровка пока не обязательна.

Future ideas:

- автоматическая расшифровка голосовых через STT;
- сохранение текста голосового в CRM;
- автотеги интересов пользователя;
- анализ возражений и частых вопросов;
- персональные follow-up сообщения через 3 дня, если пользователь интересовался услугой, но не оставил заявку или не оплатил;
- рекламные рассылки по сегментам интересов: визы, жильё, байк, soft landing, консультации.

## Идеи после v0.3.6

### Улучшение UX режима “Написать человеку”

Проблема: если пользователь быстро нажимает соседнюю кнопку после “Написать человеку”, Telegram может прислать текст старой кнопки как обычное сообщение.

Что уже сделано:

- добавлена серверная защита от пересылки названий кнопок менеджерам;
- добавлена защита в service/visa-сценариях;
- добавлена защита от ситуации, когда “Выйти в меню” улетает как вопрос по визе.

Что стоит сделать позже:

- после входа в режим диалога полностью заменять клавиатуру;
- оставить клиенту только кнопку “Закончить диалог”;
- после завершения диалога возвращать главное меню;
- проверить порядок обработчиков aiogram/FSM, чтобы быстрые клики не попадали в неправильный handler.

### Визовый агент

Развить отдельную роль визового агента:

- мини-очередь визовых клиентов;

- комментарии визового агента;
