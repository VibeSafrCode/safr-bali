# SAFR Bali — Bot MVP Flow

## Назначение документа

Этот файл описывает пользовательские сценарии Telegram-бота для MVP проекта SAFR Bali / Na Bali Team.

Цель бота в MVP:

1. принять пользователя;
2. понять его запрос;
3. показать услуги;
4. создать заявку;
5. зафиксировать реферала;
6. показать SAFR Points;
7. дать партнёрскую ссылку и QR-код;
8. уведомить админа;
9. дать админу возможность управлять заявками и начислениями.

## 1. Первый вход пользователя

### Триггер

Пользователь нажимает /start или переходит по реферальной ссылке.

### Что делает бот

1. Получает Telegram ID пользователя.
2. Проверяет, есть ли пользователь в базе.
3. Если пользователя нет — создаёт профиль.
4. Если пользователь пришёл по ref_code — фиксирует пригласившего.
5. Показывает приветственное сообщение.

### Пример сообщения

Привет. Я бот SAFR Bali / Na Bali Team.

Помогу разобраться с Бали: визы, жильё, билеты, трансфер, байк, консультации и сопровождение.

Ты уже знаешь, что тебе нужно, или пока просто изучаешь варианты?

### Кнопки

- Я уже знаю, что мне нужно
- Я пока просто смотрю
- Связаться с человеком

## 11. Выбор партнёрского режима

### Режимы

1. Direct
2. Balanced
3. Network

### Direct

Для личных рекомендаций.

Партнёр получает максимум за прямого клиента, но не получает в глубину.

### Balanced

Универсальный режим.

Партнёр получает нормально за прямого клиента и немного за второй и третий уровень.

### Network

Для кафе, QR-кодов, ресторанов, байкеров, водителей и пассивных точек.

Партнёр получает меньше за прямого клиента, но может заработать на глубине сети.

## 14. Оплата

### Главное правило

Перед оплатой бот должен уведомить владельца проекта, за что пользователь хочет заплатить.

### Логика

1. Пользователь выбирает услугу.
2. Бот собирает данные.
3. Бот уведомляет админа.
4. Админ подтверждает, что можно принимать оплату.
5. Бот отправляет ссылку на оплату или открывает оплату внутри Telegram.
6. После оплаты статус заявки меняется на paid.
7. После выполнения услуги админ подтверждает начисление SAFR Points.

## 17. Админ: подтверждение начислений

SAFR Points начисляются только после ручного подтверждения админом.

### Логика

1. Админ открывает completed-заявку.
2. Нажимает “Начислить Points”.
3. Система проверяет реферальную цепочку.
4. Система проверяет reward_rules.
5. Система создаёт записи в points_ledger.
6. Пользователь и партнёры видят начисления.

---

## 18. Что считается готовым Bot MVP

Bot MVP готов, если:

- пользователь может зайти через /start;
- пользователь сохраняется в базе;
- реферальный код фиксируется;
- пользователь видит меню;
- пользователь может создать заявку;
- админ получает заявку;
- админ может менять статус заявки;
- пользователь видит свои заявки;
- пользователь видит баланс SAFR Points;
- пользователь видит реферальную ссылку;
- пользователь видит QR-код;
- админ может вручную начислить Points;
- админ может подтвердить начисление по заявке.
