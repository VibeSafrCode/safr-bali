# Bot Content Guide

Эта папка отвечает за редактируемый контент Telegram-бота.

Здесь можно менять тексты и кнопки без переписывания основной логики бота.

## Файлы

### menu.json

Файл с кнопками главного меню.

Путь:

06 Development/bot/app/content/menu.json

Одна строка внутри main_menu — это один ряд кнопок.

Пример:

{
  "main_menu": [
    ["🏡 Найти виллу / жильё"],
    ["🛂 Визы"],
    ["💬 Консультация"],
    ["✍️ Написать человеку"]
  ]
}

Важно: сейчас логика кнопок привязана к точному тексту кнопки.

Если поменять название кнопки в menu.json, нужно проверить обработчики в:

06 Development/bot/app/handlers/menu.py
06 Development/bot/app/handlers/contact.py

Позже можно сделать более гибкую систему, чтобы менять названия кнопок без изменения логики.

---

### texts.json

Файл с основными текстами бота.

Путь:

06 Development/bot/app/content/texts.json

Здесь лежат тексты:

- start
- housing
- visa
- consultation
- points
- referral_link
- fallback

Для переноса строки используется:

\\n

Бот автоматически превращает это в нормальные переносы строк.

---

### texts.py

Технический файл, который читает texts.json.

Обычно его трогать не нужно.

Путь:

06 Development/bot/app/content/texts.py

---

## Что можно безопасно менять

Можно менять:

- формулировки текстов в texts.json
- порядок кнопок в menu.json
- эмодзи
- описания услуг
- призывы к действию

## Что менять осторожно

Осторожно менять названия кнопок:

- 🏡 Найти виллу / жильё
- 🛂 Визы
- 💬 Консультация
- ✍️ Написать человеку
- 🎁 Мои SAFR Points
- 🔗 Моя ссылка

Пока логика бота привязана к точному тексту кнопки.

## Что нельзя делать

Не удалять ключи из texts.json, если они используются в коде.

Например, нельзя удалить:

start

потому что /start берёт текст именно по этому ключу.

Не ломать JSON-формат:

- кавычки должны быть двойные
- после последнего элемента не ставить лишнюю запятую
- переносы строк писать как \\n

## Как проверить после правок

Из корня проекта:

./check_local.sh

Потом запустить бота:

cd "$HOME/Documents/AI OS SAFR/02 Projects/Bali/06 Development/bot"
source .venv/bin/activate
python -m app.main

И проверить в Telegram:

/start
