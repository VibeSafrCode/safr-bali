# SAFR v0.6.1 — Internal Mini App Catalog

Дата выпуска: 2026-07-27
Статус: production, GitHub commit `3722654`.

## Исправление

- выбор страны больше не вызывает Telegram `openTelegramLink`;
- переход `Бали → Сделать визу → E33G` происходит внутри Mini App;
- добавлена навигация направление → раздел → услуга → полный материал;
- длинные тексты разделены на внутренние страницы;
- добавлена поддержка Telegram BackButton;
- удалены `?start=` и автоматические команды боту;
- явная кнопка менеджера открывает обычный чат без команды.

## Единая архитектура контента

- создан общий типизированный каталог `web/lib/catalog.ts`;
- сайт и Mini App используют один источник;
- визовые и жилищные тексты импортируются из content JSON бота;
- Бали содержит визы, жильё, обмен и тревел-ассистента;
- Таиланд содержит обмен, визы, недвижимость и яхты;
- Россия содержит Санкт-Петербург, Урал, Кавказ и вложенные услуги;
- Непал содержит Кайлас, Эверест, Аннапурну, трансфер, жильё и гида;
- будущие услуги помечаются статусом «Скоро».
- на сайте страна, раздел, услуга и материал открываются внутри сайта.
