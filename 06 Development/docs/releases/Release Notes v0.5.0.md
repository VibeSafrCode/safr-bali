# SAFR v0.5.0 — CRM, Referrals and Staff Threads

Дата: 2026-07-25
Статус: production, задеплоен 2026-07-25.

## Пользователи и рефералы

- главный админ уведомляется о каждой новой регистрации;
- карточка показывает пользователя, источник и пригласившего;
- внешний пригласивший получает отдельное уведомление;
- повторный `/start` не создаёт дубль;
- «Моя сеть» и разделы админки используют реальные данные.

## Внутренний чат команды

- у карточки клиента есть «Внутренняя заметка» и «Чат команды»;
- менеджеры обсуждают конкретного клиента внутри отдельного thread;
- уведомления получают только назначенные сотрудники;
- клиент не получает и не видит внутренние сообщения.

## Архитектура

- JSON-хранилище вынесено в `conversation_store.py`;
- staff-сценарии вынесены в `staff_collaboration.py`;
- добавлены backend client и account service;
- добавлены `bot_runtime_events`, защищённый API и Alembic-миграции;
- добавлен идемпотентный перенос legacy JSON;
- backend недоступен — бот продолжает работать через JSON fallback.
