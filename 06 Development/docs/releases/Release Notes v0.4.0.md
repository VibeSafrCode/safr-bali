# SAFR v0.4.0 — Dynamic Pricing and Exchange

Дата: 2026-07-22
Статус: production deploy завершён.

## Изменения

- личный кабинет отображается в две колонки;
- визовые цены обновлены и показываются в IDR и USD по курсу Indodax;
- курс для цен кешируется на 3 дня, USD округляется до ближайших 5;
- услуга «Найти виллу» получила четыре страницы описания и цену от 150 USD;
- «Челябинск» переименован в «Урал», добавлен «Кавказ»;
- консультация Бали заменена разделом обмена валюты;
- добавлен калькулятор USDT → IDR наличные с суточным кешем курса и вычетом 6%;
- сохранена совместимость со старыми Telegram-кнопками и deep links.

- 4 backend regression-теста пройдены;
