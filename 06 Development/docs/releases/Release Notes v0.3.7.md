# SAFR v0.3.7 — Multi-region Release

Дата: 2026-07-20
Статус: production deploy завершён.

## Исправления

- восстановлен runtime-импорт Telegram-бота на Python 3.9;
- кнопки меню больше не теряются внутри contact/service waiting-state;
- очищается устаревший визовый контекст при выходе в меню;
- Telegram ID менеджеров дедуплицируются.

## Направления

- обычный start открывает выбор: Бали, Таиланд, Россия, Непал;
- ссылка с start=bali открывает меню Бали напрямую;
- Россия содержит Санкт-Петербург и Челябинск;
- добавлены согласованные услуги Таиланда, России и Непала;
- до наполнения карточек новые услуги показывают сообщение Скоро.

## Персональные ссылки

- новый формат ссылки не содержит ref и Telegram ID;
- код постоянный для пользователя и действует на весь бот;
- старые ссылки ref_* остаются рабочими;
- органические пользователи автоматически закрепляются за главным админом;
- startup-backfill добавляет исторических пользователей без связи и не
  перезаписывает существующие назначения.

## Надёжность и безопасность

- runtime JSON записывается атомарно;
- новые JSON-файлы получают права 0600;
- регистрация пользователя и создание referral объединены в одну транзакцию;
- ошибки рассылки фиксируются через logging.

## QA

- 18 regression-тестов Telegram-бота;
- 4 backend regression-теста;
- runtime import-check на Python 3.9;
- syntax-check bot/backend/Alembic;
- pip check обоих окружений;
- единый запуск через ./check_local.sh.

## Результат deploy

- commit `5cc5b31` опубликован в GitHub и установлен на VPS через fast-forward;
- перед обновлением проверен backup базы, runtime JSON и `.env`;
- `safr-bali-backend` и `safr-bali-bot` активны;
- `/health` и `/db/health` возвращают OK;
- polling Telegram-бота запущен без ошибок;
- у всех обычных пользователей есть реферальная привязка; главный админ
  намеренно исключён из самопривязки.

Остаётся ручной Telegram smoke-test интерфейса и ролевых сценариев.
