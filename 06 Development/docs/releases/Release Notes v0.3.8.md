# SAFR v0.3.8 — Direction Managers

Дата: 2026-07-20
Статус: release candidate, production deploy выполняется.

## Пользовательские изменения

- во всех направлениях есть кнопка «Написать менеджеру»;
- меню услуг отображаются в две колонки;
- карточки услуг Петербурга предлагают консультацию гида;
- обращения содержат страну, город, раздел и услугу.

## Роли

- главный админ получает все обращения;
- визовый админ получает только `Бали → Визы`;
- пользователь `271039578` назначается менеджером Санкт-Петербурга и получает
  только обращения по Петербургу;
- профильные менеджеры не могут отвечать или смотреть историю чужого направления.

## QA

- 21 regression-тест Telegram-бота;
- 4 backend regression-теста;
- syntax, runtime import, dependency checks и `git diff --check` пройдены.
