# SAFR Bali — Smoke Test Checklist

Короткий чеклист перед каждым релизом Telegram-бота.

---

## 1. Базовый запуск

- [ ] Бот отвечает на /start.
- [ ] Главное меню отображается.
- [ ] Кнопки главного меню нажимаются без ошибок.
- [ ] Бот не пишет “Извините, я не понял” после очевидных действий пользователя.

---

## 2. Жильё

- [ ] Нажать “Найти жильё”.
- [ ] Бот показывает карточку/меню жилья.
- [ ] Написать обычный текст: “Нужна вилла на месяц”.
- [ ] Сообщение уходит менеджерам как вопрос по жилью.
- [ ] Визовый агент не получает это обращение.

---

## 3. Консультация

- [ ] Нажать “Заказать консультацию”.
- [ ] Бот показывает текст консультации.
- [ ] Написать обычный текст: “Хочу разобрать ситуацию”.
- [ ] Сообщение уходит менеджерам как консультация.
- [ ] Визовый агент не получает это обращение.

---

## 4. Визы

- [ ] Нажать “Сделать визу”.
- [ ] Выбрать любую визу.
- [ ] Нажать “А если нет всех документов?”.
- [ ] Написать тестовый вопрос.
- [ ] Главный админ получает обращение.
- [ ] Визовый агент получает обращение.
- [ ] У визового агента есть кнопки “Ответить” и “Показать переписку”.

---

## 5. Написать человеку

- [ ] Нажать “Написать человеку”.
- [ ] Главное меню заменяется на клавиатуру диалога.
- [ ] Видна кнопка “Закончить диалог”.
- [ ] Написать обычный текст.
- [ ] Менеджер получает сообщение.
- [ ] Клиент видит подтверждение.
- [ ] Нажать “Закончить диалог”.
- [ ] Бот возвращает главное меню.

---

## 6. Защита от кнопок как текста

Проверить, что эти кнопки не улетают менеджеру как обычные сообщения:

- [ ] “Найти жильё”
- [ ] “Заказать консультацию”
- [ ] “Сделать визу”
- [ ] “Выйти в меню”
- [ ] “Показать меню”
- [ ] “Написать человеку”
- [ ] “Закончить диалог”

---

## 7. Админские действия

- [ ] Главный админ видит карточку клиента.
- [ ] Главный админ может нажать “Ответить”.
- [ ] Ответ доходит клиенту.
- [ ] Главный админ может нажать “Показать переписку”.
- [ ] Главный админ видит историю.
- [ ] Главный админ видит кнопку “Передать на визы”.

---

## 8. Визовый агент

- [ ] Визовый агент не получает жильё.
- [ ] Визовый агент не получает консультации.
- [ ] Визовый агент получает визовые обращения.
- [ ] Визовый агент получает клиента после “Передать на визы”.
- [ ] Визовый агент может ответить только доступному визовому клиенту.
- [ ] Визовый агент может открыть историю только доступного визового клиента.

---

## 9. VPS после деплоя

На VPS проверить:

- [ ] systemctl status safr-bali-bot показывает active/running.
- [ ] journalctl не показывает Unauthorized.
- [ ] journalctl не показывает Conflict.
- [ ] journalctl не показывает Traceback.
- [ ] В логах есть Run polling for bot.

---

## 10. Git flow

Перед деплоем:

- [ ] git status --short на Mac чистый или понятный.
- [ ] Коммит создан.
- [ ] Push в GitHub прошёл.

После деплоя:

- [ ] VPS сделал git pull origin main.
- [ ] Бот перезапущен.
- [ ] Бот active/running.

---

## 11. Website и Cloudflare Tunnel

- [ ] `https://safrway.online` отвечает `200`.
- [ ] `https://www.safrway.online` отвечает redirect на основной домен.
- [ ] `https://app.safrway.online` отвечает `200`.
- [ ] `https://api.safrway.online/health` отвечает `200`.
- [ ] `cloudflared-safrway.service` active/running.
- [ ] Существующий MDT618 Tunnel не перезапускался и отвечает штатно.

---

## 12. Telegram Mini App

- [ ] Открыть Mini App кнопкой из Telegram.
- [ ] Нажать `Бали` — приложение остаётся открытым.
- [ ] Нажать `Сделать визу` — видны E33G, D12, D1/D2, C1 и eVOA.
- [ ] Открыть E33G — полный текст отображается внутри Mini App.
- [ ] Кнопки страниц переключают длинный текст без выхода из приложения.
- [ ] Кнопка «Назад» возвращает к разделам Бали.
- [ ] Telegram BackButton возвращает на предыдущий уровень.
- [ ] Таиланд показывает обмен, визы, недвижимость и яхты.
- [ ] Россия показывает Санкт-Петербург, Урал и Кавказ.
- [ ] Непал показывает Кайлас, Эверест, Аннапурну, трансфер, жильё и гида.
- [ ] Ни одна кнопка каталога не отправляет `/start` в бот.
- [ ] «Написать менеджеру» открывает обычный чат без автоматической команды.
- [ ] Баланс, сеть и заявки продолжают загружаться.
