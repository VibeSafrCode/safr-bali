## 1. Базовый запуск

- [ ] Бот отвечает на /start.
- [ ] Главное меню отображается.
- [ ] Кнопки главного меню нажимаются без ошибок.
- [ ] Бот не пишет “Извините, я не понял” после очевидных действий пользователя.

---

## 2. Жильё

- [ ] Нажать “Найти жильё”.
- [ ] Бот показывает карточку/меню жилья.
- [ ] Написать обычный текст: “Нужна вилла на месяц”.
- [ ] Сообщение уходит менеджерам как вопрос по жилью.
- [ ] Визовый агент не получает это обращение.

---

## 3. Консультация

- [ ] Нажать “Заказать консультацию”.
- [ ] Бот показывает текст консультации.
- [ ] Написать обычный текст: “Хочу разобрать ситуацию”.
- [ ] Сообщение уходит менеджерам как консультация.
- [ ] Визовый агент не получает это обращение.

---

## 4. Визы

- [ ] Нажать “Сделать визу”.
- [ ] Выбрать любую визу.
- [ ] Нажать “А если нет всех документов?”.
- [ ] Написать тестовый вопрос.
- [ ] Главный админ получает обращение.
- [ ] Визовый агент получает обращение.
- [ ] У визового агента есть кнопки “Ответить” и “Показать переписку”.

---

## 5. Написать человеку

- [ ] Нажать “Написать человеку”.
- [ ] Главное меню заменяется на клавиатуру диалога.
- [ ] Видна кнопка “Закончить диалог”.
- [ ] Написать обычный текст.
- [ ] Менеджер получает сообщение.
- [ ] Клиент видит подтверждение.
- [ ] Нажать “Закончить диалог”.
- [ ] Бот возвращает главное меню.
