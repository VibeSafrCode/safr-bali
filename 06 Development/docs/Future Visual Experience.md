# SAFRWAY Future Visual Experience

Дата: 2026-07-28  
Статус: архитектурная точка расширения, тяжёлая графика не реализована

## Назначение

Будущий визуальный каталог стран может показывать направления как планеты,
орбиты или интерактивную карту. Этот слой не получает право владеть
маршрутизацией, контентом или бизнес-логикой.

Текущая точка расширения:

`06 Development/astro-site/src/components/DestinationExperience.astro`

Сейчас компонент создаёт только статический HTML fallback. Он работает без
JavaScript и содержит обычную ссылку на каждый доступный Astro route.

## Будущий интерфейс

Интерактивный модуль получает только сериализуемые публичные данные:

```ts
type DestinationVisualItem = {
  id: string;
  name: string;
  href: string;
  status: "available" | "soon";
  visualKey: string;
};
```

Модуль может быть реализован как React island, Canvas или WebGL, но обязан:

- загружаться лениво через `client:visible` или более строгий режим;
- иметь feature flag и быть выключенным по умолчанию;
- сохранять существующий статический HTML fallback;
- использовать обычные Astro URL;
- не содержать единственную копию текста или ссылок;
- учитывать `prefers-reduced-motion`;
- иметь облегчённую мобильную версию;
- не входить в initial bundle остальных SEO-страниц;
- не подключать Telegram SDK;
- не обращаться к пользовательской сессии.

## SEO и доступность

Даже при включённой визуализации:

- поисковый контент остаётся в HTML;
- Canvas/WebGL получает `aria-hidden`, если дублирует навигацию;
- клавиатурная навигация работает через fallback;
- один H1, canonical, breadcrumbs и JSON-LD создаёт Astro;
- URL не меняются;
- без JavaScript пользователь проходит тот же маршрут.

## Performance gate

До включения модуль должен отдельно пройти:

- Lighthouse performance не ниже 95;
- axe WCAG A/AA без нарушений;
- мобильную проверку прокрутки;
- `prefers-reduced-motion`;
- budget для lazy chunk;
- отсутствие layout shift;
- fallback при ошибке загрузки.

В B2 никакие тяжёлые зависимости, анимации, Canvas или WebGL не добавлены.
