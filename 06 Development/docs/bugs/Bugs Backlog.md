## Актуальные баги

### BUG-001 — После некоторых разделов меню текст не считывается как обращение

Статус: fixed
Коммит: 968e922 Fix service text waiting for consultation and housing  
Приоритет: высокий  
Дата: 2026-07-08

#### Симптом

Пользователь нажимает:

- `🏡 Найти жильё`
- `💬 Заказать консультацию`

Бот показывает нормальный текст раздела.

Но если пользователь после этого пишет обычный текст, например:

- `Привет`
- `Разобрать ситуацию`
- `Нужна вилла`

бот отвечает:

> Извините, я не понял, что вы хотите.

#### Причина

Не все разделы переводят пользователя в режим ожидания следующего сообщения.

Например, `💬 Заказать консультацию` показывает текст, но не кладёт пользователя в `SERVICE_WAITING_USERS`.

#### Что нужно сделать

Проверить `06 Development/bot/app/handlers/menu.py`.

Нужно пройти все основные сценарии:

- `💬 Заказать консультацию`
- `🏡 Найти жильё`
- жильё / видео / риски аренды
- `🛂 Сделать визу`
- конкретные визы
- `❓ А если нет всех документов?`
- `✍️ Написать человеку`
- `📋 Выйти в меню`
- `📋 Показать меню`

Ожидаемая логика:

- если раздел просит пользователя написать текст — включать ожидание текста;
- следующий текст должен уходить нужной группе;
- после отправки состояние ожидания должно очищаться.

### BUG-003 — Нужен единый helper для всех кнопок меню

Статус: fixed
Коммит: 3d4b29d Add shared known button helper  
Приоритет: высокий  
Дата: 2026-07-08

#### Суть

Сейчас защита от кнопок меню размазана по разным местам.

Нужно сделать один общий helper:

`is_known_button_text(text)`

Он должен учитывать кнопки из:

- `app/content/menu.json`
- housing keyboard
- visa keyboard
- client dialog keyboard
- admin keyboards
- service keyboards

И использоваться везде, где бот принимает свободный текст.

### CODE-REVIEWED — BUG-004: логика визового агента проверена по коду

Дата: 2026-07-08

- визовый агент не получает жильё;
- визовый агент не получает консультации;

- кнопка `Передать на визы` отправляет клиента визовому агенту;
