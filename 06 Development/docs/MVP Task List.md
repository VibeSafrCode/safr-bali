# SAFR Bali — MVP Task List

## Назначение документа

Этот файл описывает порядок разработки MVP проекта SAFR Bali / Na Bali Team.

MVP должен быстро запустить Telegram-first систему, которая позволяет:

- принимать заявки;
- фиксировать пользователей;
- фиксировать рефералов;
- начислять SAFR Points;
- показывать баланс;
- давать партнёрскую ссылку и QR-код;
- управлять заявками через админку;
- менять правила начислений без пересчёта старых операций.

## Этап 10. Тестовый сценарий MVP

MVP нужно проверить на одном полном сценарии.

### Тест

1. Партнёр А заходит в бота.
2. Получает ссылку.
3. Клиент Б заходит по ссылке.
4. Клиент Б создаёт заявку.
5. Админ видит заявку.
6. Админ меняет статус.
7. Админ ставит completed.
8. Админ начисляет Points.
9. Партнёр А видит баланс.
10. Клиент Б видит свою заявку.

Статус: todo

---

## Что считается готовым первым MVP

MVP готов, если:

- /start работает;
- пользователь сохраняется;
- ref_code работает;
- услуга выбирается;
- заявка создаётся;
- админ получает заявку;
- админ меняет статус;
- баланс показывается;
- points_ledger сохраняет операции;
- реферальная ссылка работает;
- QR-код работает;
- админ может вручную начислить Points;
- старые начисления не пересчитываются.
