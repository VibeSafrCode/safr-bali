# SAFRWAY — Partners / B2B, все десять локалей

**Дата сборки:** 2026-10-09
**Задача:** передать Codex самодостаточный пакет одной B2B-страницы SAFRWAY для всех текущих языков.

## Порядок

1. `CODEX_PROMPT_RELEASE_ALL_RU.md` — единое рабочее задание для Codex.
2. `CONTENT_IMPORT_STAGING.json` — 10 редакционных записей одной страницы: RU+9 языков, SEO/основной текст/CTA. Это staging, не API сайта.
3. `CONTENT/{RU,EN,DE,ZH-HANS,KO,FR,JA,HI,ES,AR}/` — полные исходные Markdown, доступные также для ручной проверки.
4. `QA/validate_bundle.py --self-test` — структурная проверка и негативные контрольные кейсы.
5. `QA/QA_REPORT_RU.md` — фактический объём проверок и ограничения.
6. `SHA256SUMS.txt` и `MANIFEST.json` — контроль целостности.
7. `INTERNAL/` — контекст и черновик Referral; **не публиковать как страницу**.
8. `SAFRWAY_CHAT_CONTEXT_CURRENT_v69.md` — продолжение проекта.

**Исходный русский текст не менялся по сравнению с первой/второй партией.** Его статус `RU_REVIEW`, поскольку пользователь предпочёл окончательно смотреть на живом сайте. Новые HI/ES/AR — модельные переводы, не сертификат от носителей языка. Корректность работы CTA, SEO/robots, RTL и реальные URL подтверждаются только Codex после интеграции.

**Продолжать с текущей инфраструктурой**: не создавать второй Registry, CRM, новый pricing pipeline или новый Referral backend. Публичных процентов вознаграждения/фиксированной цены для Partners/Referral пока нет.
