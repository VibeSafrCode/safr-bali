## Смысловые запреты и ограничения

- Фиксированные комиссии, B2B-проценты, гарантированные выплаты, exclusivity/white-label отсутствуют как подтверждённые условия.
- SAFRWAY не гарантирует выдачу визы/KITAS: окончательное решение принимает уполномоченный госорган.
- Запрос минимальных данных до оформления, личные документы — через согласованный защищённый канал.
- Возможность оказания услуги и конкретные сроки/исполнители проверяются по каждому обращению.
- Referral исключён из публичного импортного набора, хранится `INTERNAL` с `preview_only_not_indexable`, пока владелец не предоставит условия.
- `ar` имеет направление `rtl`; визуальный контроль сайта необходим после внедрения.
- Редакционный контент не предусматривает ни одного hardcoded URL на неготовую страницу Referral. Связанные услуги задаются стабильными ключами, реальные ссылки разрешает Codex только на опубликованные локализованные URL.

## Ограничения

1. Автоматическая проверка равного числа структурных элементов, ключевых смысловых фраз и SHA-256 сама по себе не доказывает идеальное качество перевода.
2. Исходный RU документ сохраняет `RU_REVIEW`; пользователь согласовал подготовку и предпочитает финально проверить страницу на работающем сайте.
3. Схема импорта `safrway_editorial_staging_not_runtime_v1` — промежуточный контракт. Реальные `serviceId`, `contentId`, CRM и URL нужно сверить Codex.
4. Нельзя заявлять о реальной публикации/индексации, пока Codex не покажет deployed commit SHA, реальные public URL, canonical/hreflang/robots/sitemap, успешный browser QA с VibeDiz.
5. Проверены только тексты страницы Partners. Реферальные выплаты и договорные условия остаются отдельным нерешённым продуктовым вопросом.
