# Working KITAS E23とE33G：インドネシアで働くにはどちらが適切？

## 要点

**E23とE33Gは異なる在留資格の根拠です。** Working KITAS E23は認められたケースでインドネシアの雇用主のもとで働くための資格です。E33Gはインドネシア国外の企業のためにリモート勤務する人向けです。ノートパソコンの場所より、実際の雇用主が重要です。

## 主な違い

| 項目 | Working KITAS / E23 | Remote Worker / E33G |
|---|---|---|
| 対象 | インドネシアの企業に雇用される外国人専門職 | 海外企業のために働く専門職 |
| 雇用書類の発行者 | インドネシアの雇用主 | 海外の雇用主 |
| インドネシアの労働承認 | 適用法令に応じたRPTKAなど | 現地就労の許可の代わりにはならない |
| 期間 | ビザ区分と雇用根拠による | E33G固有の規則による |
| 別の現地企業での就労 | 自動的には許可されない | E33Gだけでは認められない |

この表は各資格の目的を説明するもので、特定の人が取得できると判断するものではありません。

## バリ島の企業に雇用される場合

実際に現地企業で働く場合は[Working KITAS E23](/ja/bali/visas/working-kitas/)を検討し、会社、職務、労働承認を確認します。雇用主側では[RPTKA](/ja/bali/business/foreign-worker-permits/)と[WLKP](/ja/bali/business/wlkp/)は別々の重要事項です。

## 雇用主が海外にいる場合

海外企業のリモート従業員には[E33G Remote Worker KITAS](/ja/bali/visas/e33g/)が適する可能性がありますが、雇用契約、所得証明、許可される活動について独自の要件があります。インドネシアの顧客のために働いたり、現地の社員になったりする万能な手段ではありません。

## 会社を所有している場合

[Investor KITAS E28A](/ja/bali/visas/investor-kitas/)は本人の持分要件を持つ第三の独立した区分です。PT PMAを設立しただけでE28Aの資格があるとは限らず、投資だけであらゆる会社に勤務できるわけでもありません。

## 観光ビザで入国した場合

将来の申請を前提に仕事を始めないでください。[Working KITASへの資格変更の確認](/ja/bali/visas/working-kitas/conversion/)では元のビザ区分、期限、適法な方法を調べます。すべての資格が出国なしで変更できるわけではありません。

## よくある質問

### E33Gで現地企業に勤められますか？

E33Gは海外雇用主のための勤務を想定しています。インドネシア企業で働くには適切な就労根拠を別途確認する必要があります。

### E23はバリ島のすべてのフリーランサーに適していますか？

自動的には当てはまりません。雇用主、職務、適用される労働手続きを確認します。

### E23とInvestor KITASはどう違いますか？

E23は雇用、E28Aは外国人投資家の企業参加に関する別の条件に基づきます。相互に代用できません。

### E23を持つすべての人にRPTKAが必要ですか？

多くの場合、雇用主にRPTKAが必要ですが、法定の例外もあります。具体的な根拠を確認します。

### まずE33Gを取り、あとから現地で就職できますか？

現地就労を始める前に資格と許可を別途確認する必要があります。E33Gだけでは働けません。

### どちらの資格が安いですか？

申請料金だけの比較は適切ではありません。根拠、書類、雇用主の義務、追加費用が異なります。

## 適切なKITASを選ぶ
