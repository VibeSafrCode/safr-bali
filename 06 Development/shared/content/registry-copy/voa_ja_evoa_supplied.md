# インドネシア eVOA — ビザを準備した状態でバリに到着

バリへ休暇や短期滞在で行く場合、eVOAはインドネシア入国を準備するうえで非常に便利な選択肢です。

旅行前に電子的に申請し、入国後は最長30日滞在できます。必要であれば1回だけ、さらに最長30日延長できます。

つまり、1回の入国で合計最長60日まで滞在できます。

## eVOAはどんな人に向いていますか？

次のような場合に検討できます。

- バリやインドネシアの他地域へ短期旅行する
- 出発前にビザを済ませたい
- 初回最長30日の滞在を希望する
- さらに30日延長し、合計60日まで滞在する可能性を残したい
- 到着後の手続きを減らしたい
- 最初から長期ビザは必要ない

すでに数か月滞在する予定が決まっている場合は、eVOAではなくC1など長期向けの選択肢も比較してください。

## eVOAと空港VOAの違い

どちらもVisa on Arrivalで、基本の滞在期間は同じです。

実際の違いは「いつ手続きするか」です。

- **eVOA** — 旅行前にオンライン
- **VOA** — インドネシア到着後

### 到着後に通常のVOAを取得する場合

空港で別のビザ手続きが必要です。

1. Visa on Arrivalエリアを探す
2. 空港の銀行/支払いカウンターで支払う
3. 支払い確認またはvoucherを受け取る
4. その後、ビザ手続きと入国審査を続ける

到着便が集中する時間帯は、待ち時間が長くなる場合があります。非常に混雑するピーク時には、旅行者や空港サービス事業者の実務報告で、VOAと入国審査を合わせて約2〜3時間かかった事例もあります。これは公式平均ではなく、ピークケースです。

さらに到着後に現金の両替が必要な場合は、もう一つ立ち寄る場所が増えます。空港の両替レートが常に最も有利とは限りません。

### eVOAを事前に準備している場合

すでに発給されたビザを持って到着します。

空港でVOAを**購入する必要がなく**、支払いvoucherを受け取る必要もありません。

パスポート、eVOA、入国地点が現在のautogate条件を満たしていれば、通常の有人カウンターではなく自動入国審査を利用できる場合があります。

そのため、eVOAは到着全体を大きく簡略化できます。

## All Indonesiaも対応できます

国際線でインドネシアに入国する場合は**All Indonesia**も必要です。

この申告は以下の情報を統合します。

- 入国管理
- 税関
- 健康
- 検疫

到着前に入力でき、提出後にQRコードが発行されます。

政府の申告自体は無料です。

追加のフォームを自分で処理したくない場合、**SAFRWAYがAll Indonesiaを代行できます**。

完全に準備した到着は次のようになります。

**eVOA → All Indonesia → 帰国/乗継航空券 → 送迎 → 必要に応じて両替。**

## 重要事項

eVOA/VOAは短期の訪問ビザです。

観光、家族訪問、会議など許可された短期目的には適していますが、就労ビザではありません。

長く滞在する予定なら、出発前にC1、D12、E33Gを比較してください。
