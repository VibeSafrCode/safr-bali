# E33G 家庭申请：如何为配偶和孩子办理 KITAS

主申请人：E33G Remote Worker KITAS。 配偶：单独的 E31B 家庭 ITAS。 孩子：单独的 E31E 家庭 ITAS。 E31E：未满 18 岁且未婚的亲生孩子。

## 关键信息

- 主申请人：E33G Remote Worker KITAS。
- 配偶：单独的 E31B 家庭 ITAS。
- 孩子：单独的 E31E 家庭 ITAS。
- E31E：未满 18 岁且未婚的亲生孩子。
- 家庭 ITAS 不是工作签证。
- 证明材料：婚姻或出生文件以及主申请人的身份。
- 是否需要翻译、海牙认证或领事认证，取决于签发国家及文件。

家庭中的一人获得 [E33G Remote Worker KITAS](/bali/visas/e33g/)，并不意味着配偶和孩子会自动取得以该 E33G 在印度尼西亚居住的权利。

每位家属都需要独立、合法的身份。ITAS 持有人的家庭可使用家庭团聚类别。

本文所述类别对应为：

- **E31B**：ITAS / ITAP 持有人的配偶；
- **E31E**：加入 ITAS / ITAP 持有人父母的未满 18 岁、未婚亲生子女。

标准家庭结构可以是：

**主申请人 E33G → 配偶 E31B → 孩子 E31E。**

## 配偶：E31B

E31B 是外国人加入持有 ITAS 或 ITAP 的丈夫或妻子的家庭类别。

主申请人取得 E33G 后，配偶可依据婚姻关系和主申请人的有效身份，单独申请家庭身份。

这是独立申请，也会形成独立 ITAS。配偶不会因此成为 E33G 持有人，也不会自动继承主申请人的远程工作许可。

## 配偶需要哪些材料？

首先需要证明两件事：

1. 婚姻在法律上存在；
2. 家庭主申请人在印度尼西亚拥有适用的有效身份。

初步审核通常准备：

- 配偶护照；
- 结婚证明；
- E33G 主持有人护照；
- 主持有人的 E33G / e-ITAS；
- 当前申请表要求的其他信息和文件。

根据结婚证明签发国家，可能需要：

- 海牙认证（apostille）；
- 领事认证；
- 翻译；
- 符合要求的翻译认证或格式。

在经理查看原件和签发国家之前，不要随意提前购买翻译服务。

## 孩子：E31E

本文描述的分类将 E31E 用于 ITAS / ITAP 持有人的亲生子女。

条件包括：

- 是亲生子女；
- 未满 18 岁；
- 未婚；
- 加入持有 ITAS / ITAP 的父母。

满足条件时，可为 E33G 持有人的孩子单独准备家庭 ITAS 申请。

## 孩子需要哪些材料？

关键文件是出生证明，用来证明与主要 ITAS 持有人的亲子关系。

初次审核通常需要：

- 孩子的护照；
- 出生证明；
- E33G 父母一方的护照；
- 该父母有效的 E33G / e-ITAS；
- 如果用于关联文件，需要父母结婚证明；
- 根据家庭结构和当时要求提供的其他材料。

出生证明也可能需要海牙认证或领事认证及翻译。

## 是否必须先取得主申请人的 E33G？

SAFRWAY 的通常流程是先建立主申请人的 E33G 个案，再在其身份和材料能够支持家属申请时提交家属。

这样可降低家属申请无法正确关联主申请人身份的风险。

如果当前系统允许使用已签发的签证或其他已确认身份，个别情况可以采用不同顺序。因此，应在提交全家申请前确定流程。

## 全家能同时申请吗？

不能把同时申请视为通用规则。顺序取决于：

- 主申请人的 E33G 办理阶段；
- 已经签发了哪些文件；
- 当前 eVisa 系统要求；
- 每位家属的类别；
- 家庭材料。

SAFRWAY 会提前安排顺序，避免在依据不足时提交家属申请。

## 家庭 ITAS 的有效期

家庭身份与 E33G 分开办理。本文所述 E31 类别可根据具体类别及依据对应不同 ITAS 期限。

不要默认家属文件的有效期一定与主 E33G 完全一致。

提交前我们会检查：

- 家庭类别可用期限；
- 主持有人身份的剩余期限；
- 如何协调全家到期日期。

目标是尽可能避免一家人的证件在不方便的不同日期到期。

## 配偶可以持 E31B 工作吗？

E31B 是家庭身份，不是独立的远程工作者 E33G。取得家属 ITAS 不代表可以自动进行任何工作。

如果配偶也：

- 从事远程工作；
- 计划为印度尼西亚公司工作；
- 经营业务；
- 在印度尼西亚获得收入，

需要单独评估实际活动是否适合家庭身份，还是需要本人工作或经营身份。

## 孩子可以上学吗？

家庭身份解决合法居留问题，但学校可以有自己的要求。

学校可能索要：

- 护照；
- ITAS；
- 出生证明；
- 居住地址；
- 医疗资料；
- 其他文件。

移民身份和学校入学彼此相关，但属于不同手续。

## 家属必须具有相同国籍吗？

不应假定全家必须拥有同一国籍。更重要的是：

- 有法律证明的亲属关系；
- 有效护照；
- 正确准备的民事文件；
- 适用的主申请人身份。

夫妻或孩子国籍不同时请告诉经理，材料和认证要求可能不同。

## 婚姻不在国籍国登记怎么办？

这很常见，例如：

- 夫妻是一个国家的公民；
- 在另一个国家登记结婚；
- 生活在第三个国家。

需要确认：

- 证明在哪里签发；
- 文件是否被认可；
- 是否需要海牙认证；
- 是否需要翻译；
- 是否需要额外婚姻登记记录。

请先把原始文件交给经理。

## 结婚或出生证明不是英文怎么办？

不要只为“备用”而先做翻译。先判断具体文件要求。

可能需要：

- 英文翻译；
- 印尼文翻译；
- 宣誓或认证译员；
- 翻译前先做海牙认证；
- 其他准备顺序。

SAFRWAY 会先看原件，再说明正确步骤。

## 父母没有结婚怎么办？

对孩子而言，关键是与父母的法律关系。

如果涉及：

- 父母未婚；
- 姓氏不同；
- 证明上未列出一方父母；
- 收养；
- 监护；
- 再婚；
- 前段婚姻的孩子，

不要仅凭类别名称自行判断。

**把材料发给 SAFRWAY 经理，我们会判断哪一类别与真实法律关系相符。**

## 能否为 E33G 持有人的父母办理？

本文所述家庭 ITAS 分类还包括 **E31H**，用于父母加入持 ITAS / ITAP 的子女。

但这是单独的家庭场景，不应自动并入“E33G＋配偶＋孩子”方案。

SAFRWAY 会核查：

- E31H 是否适用；
- 主要持有人的身份；
- 亲属关系证明；
- 可用期限；
- 当前申请要求。

## 家属与 E33G 主持有人权利相同吗？

不同。主申请人和家属的居留依据不同：

- E33G 的依据是为外国雇主远程工作；
- E31B 的依据是配偶团聚；
- E31E 的依据是子女团聚。

不能把主申请人可从事的活动自动转移给家属。

## 什么时候开始准备家庭手续？

最好在提交主 E33G 前就考虑家属。并不需要所有人同一天申请。

开始前可先检查：

- 全家护照；
- 结婚证明；
- 出生证明；
- 姓名拼写；
- 海牙认证或领事认证；
- 翻译；
- 护照有效期。

这样可以避免主 E33G 签发后，再为修正家庭文件而耽误时间。

## 为什么要核对姓名？

国际家庭常见不同音译，例如：

- 护照上一种拼法；
- 结婚证明上另一种；
- 孩子的证明上又不同。

不一定都是严重问题，但应在申请前发现。SAFRWAY 将全家材料作为相互关联的一整套文件核对。

## 初次家庭审核需要什么？

通常先提供以下资料。

### E33G 主持有人

- 护照；
- 已签发时提供 E33G / e-ITAS；
- 当前办理阶段。

### 配偶

- 护照；
- 结婚证明。

### 孩子

- 护照；
- 出生证明。

然后可确定：

- 类别；
- 提交顺序；
- 是否需要海牙认证或领事认证；
- 翻译要求；
- 补充材料。

## 常见问题

### 配偶会自动包含在 E33G 中吗？

不会。配偶需要独立家庭身份。

### E33G 配偶使用什么类别？

本文描述 E31B 为 ITAS / ITAP 持有人配偶的类别。

### 孩子是什么类别？

E31E 用于加入 ITAS / ITAP 父母的未满 18 岁、未婚亲生子女。

### 孩子需要单独护照吗？

独立移民申请需要符合要求的有效旅行证件。应结合孩子实际文件审核。

### 可以在 E33G 后申请家属吗？

可以，这是本文所述标准流程。

### 家庭材料能提前准备吗？

可以，而且建议如此。最好在主 E33G 签发前检查婚姻和出生文件。

### 配偶持家庭 KITAS 可以工作吗？

不能把家庭 ITAS 视为通用工作许可，必须单独检查实际活动。

### 父母可以申请吗？

分类中有 E31H，用于加入持 ITAS / ITAP 子女的父母，需个案核查。

### 证明需要翻译吗？

取决于语言、签发国家和当前要求。先发送原件。

### 非标准家庭怎么办？

联系经理并提交文件。SAFRWAY 会依据法律关系确定适用类别。
