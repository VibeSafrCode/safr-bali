# Preview brand invariants

- This registry is a build-time preview contract, not an identity, referral, pricing or access-control store. Request Host, referrer, query and Telegram start payload cannot grant partner rights.
- SAFRWAY stays the default. Unknown brands fail closed. York uses a separate source/output directory and loopback-only static server without the live preview plugins.
- Import the current shared catalog, approved Registry content and canonical price bindings; never create a brand-specific rate, FX formula or translation/content fork.
- Keep synthetic roles visibly marked. Do not connect real accounts, Telegram, client records, commercial overrides or ledgers as part of YG2.
- Publication, private HTTPS access and production hosts require their own explicit gate. Noindex is not access control. Secrets and customer records must never enter this registry or an AUDIT packet.
