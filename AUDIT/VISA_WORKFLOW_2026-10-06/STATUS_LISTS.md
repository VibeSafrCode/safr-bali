# Два списка визовых статусов

Левая колонка — работа SAFRWAY и оплата клиента. Правая — подтверждённый внешний этап. Это независимые поля; одинаковые слова «оплачено» и «в работе» в них относятся к разным участникам процесса. Состояние действия самой визы хранится отдельно.

## Левая колонка

| Статус | Код | Значение |
| --- | --- | --- |
| Заявка от клиента — новый | `CLIENT_REQUESTED` | Клиент обратился; команда ещё не приняла заявку в работу. |
| Заявка принята | `PURCHASED` | Услуга зарегистрирована и принята SAFRWAY. Это не подтверждение оплаты. |
| Ожидаем оплату | `WAITING_PAYMENT` | Ожидаем оплату клиента SAFRWAY, не оплату внешнего процесса. |
| Оплачено | `PAID` | Менеджер подтвердил оплату клиента. Выбор статуса не меняет платёжные записи. |
| Ожидаем документы | `DOCUMENTS_REQUIRED` | Не хватает данных или документов клиента для продолжения. |
| Документы получены | `DOCUMENTS_RECEIVED` | Документы получены, но ещё не обязательно проверены или поданы. |
| Проверяем документы — новый | `UNDER_REVIEW` | SAFRWAY проверяет комплект перед подачей; это не рассмотрение иммиграцией. |
| Требуются исправления — новый | `REVISION_REQUIRED` | Перед подачей нужно исправить конкретные данные или документы. |
| Готово к подаче — новый | `READY_TO_SUBMIT` | Комплект подготовлен; передача во внешнюю систему ещё не подтверждена. |
| Заявка подана | `SUBMITTED` | SAFRWAY подтвердил передачу заявки. Решения по ней ещё может не быть. |
| В работе · In Progress | `PROCESSING` | SAFRWAY продолжает работу по кейсу. Не означает ожидание выдачи или одобрение. |
| Требуется действие | `ACTION_REQUIRED` | Нужен конкретный следующий шаг клиента или команды; укажите его в поле действия. |
| Документ передан клиенту — новый | `DELIVERED` | Готовый документ передан клиенту; способ передачи сохраняется в истории. |
| Оформление завершено | `COMPLETED` | Работа SAFRWAY по этой услуге завершена. Это не срок действия визы. |
| Оформление отменено | `CANCELLED` | Работа SAFRWAY остановлена; это не автоматическая отмена визы или заявления в иммиграции. |

## Правая колонка

| Статус | Код | Значение |
| --- | --- | --- |
| Этап не указан | `UNKNOWN` | Подтверждённого внешнего этапа нет. Не угадываем значение неоднозначного Pending. |
| Заявка передана | `SUBMITTED` | Заявка передана во внешний процесс. Наличие квитанции о получении уточняется отдельно. |
| Ожидается оплата иммиграции | `WAITING_PAYMENT` | Во внешнем процессе ожидается сбор или платёж. Оплата клиентом SAFRWAY хранится слева. |
| Оплата иммиграции подтверждена | `PAID` | Подтверждена оплата внешнего процесса; это не одобрение заявления. |
| Ожидается проверка — новый | `WAITING_VERIFICATION` | Заявка ожидает проверки; начало активного рассмотрения ещё не подтверждено. |
| На рассмотрении · In Progress | `PROCESSING` | Внешний орган рассматривает заявление. Не означает, что оно одобрено или готово к выдаче. |
| Требуется действие по заявлению | `ACTION_REQUIRED` | Есть подтверждённый запрос данных, исправлений или другого действия. Само слово Pending недостаточно. |
| Требуется биометрия | `BIOMETRICS_REQUIRED` | Подтверждён запрос биометрии. Дата и необходимые действия указываются отдельно. |
| Требуется интервью — новый | `INTERVIEW_REQUIRED` | Подтверждён запрос интервью; детали и дату нужно уточнить. |
| Ожидается подтверждение офицера — новый | `WAITING_OFFICER_CONFIRMATION` | Внешний процесс ожидает подтверждения сотрудника; решение или выдача ещё не подтверждены. |
| Рекомендовано к одобрению — новый | `RECOMMENDED_APPROVAL` | Есть рекомендация одобрить, но окончательное одобрение и выдача ещё не подтверждены. |
| Ожидается решение — новый | `WAITING_DECISION` | Ожидается финальное решение. Это не положительный результат. Неоднозначное Decision требует уточнения. |
| Одобрено | `APPROVED` | Подтверждено положительное решение по процессу. Получение готового документа отмечается отдельно. |
| Ожидаем выдачу документа — новый | `AWAITING_ISSUANCE` | Менеджер отдельно подтвердил ожидание формирования документа. Не выводится из оплаты или In Progress. |
| Документ выдан — новый | `ISSUED` | Выдача документа подтверждена. Активация визы, въезд и передача клиенту — отдельные данные. |
| Рассмотрение завершено — новый | `FINALISED` | Внешний процесс завершён. Сам статус не говорит, одобрена ли заявка; итог уточняется отдельно. |
| Отказано | `REJECTED` | Зафиксирован подтверждённый отказ во внешнем процессе. |
| Отменено / отозвано | `CANCELLED` | Подтверждено прекращение внешнего процесса; основание сохраняется отдельно. Запрос отзыва ещё не означает отзыв. |

## Пример согласованного состояния

Клиент оплатил SAFRWAY, заявление находится в иммиграции на рассмотрении, а выдача документа ещё не подтверждена: слева PAID, справа PROCESSING, состояние визы NOT_ISSUED.

Оригинальную формулировку внешней системы менеджер сохраняет отдельно в поле raw_external_status. Автоматической нормализации неоднозначных слов Pending и Decision нет. Эти списки — понятные этапы SAFRWAY, а не утверждение о единой официальной терминологии всех иммиграционных систем.
