## Production outcome

Final status: ROLLED_BACK / EDGE RELEASE BLOCKED, not DEPLOYED.
In addition to the two initial b3804eb rollbacks, the corrected 1c89101 candidate
was rolled back three times during live verification (premature cache check,
unbounded readiness check, final edge-header failure). Each retained original
static roots/config; the last rollback is authoritative.

All origin bytes/cache/security/auth/health assertions passed after activation.
Public HTTPS verified exact SW/offline/CSS/manifest bytes and build ID. Two final
fresh browser contexts each passed seven exact public HTML routes, mobile image
decode/overflow, exact six-key page/worker v3 cache, exact offline HTML, native
GET retry, online recovery and zero runtime/CSP errors. Public/app pricing returned
identical 28 items, catalog1, fresh FX/projection13238 during a recorded check.
These are historical activation observations, not current active-release claims.

Earlier browser smoke falsely treated a Promise as truthy in Playwright 1.51
`waitForFunction(async ...)`; local reproduction returned false/empty caches
prematurely. Node-side polling of an evaluated synchronous controller state fixed
that check without weakening cache assertions. One intervening unbounded ready
wait did not finish; cause remains inconclusive, not a proven data-cache leak.
Final smoke enforces both a 15-second readiness limit and total execution deadline.

Repeated HTTPS verification then failed the CSS CSP-header assertion. Origin
still returned the expected bytes/headers, but Cloudflare can serve public assets
with old or overridden headers: CSS max-age14400 instead of origin0; icons retain
max-age31536000/immutable and lack CSP/nosniff. One icon HIT had age87608 seconds.
After rollback, the newly added CSS was correctly absent at origin, but its edge
404 also carried max-age14400. No customer/API response was observed cached.
The failed HTTP verifier was initially followed by a successful origin command;
that shell's exit0 is NOT a combined PASS. The failed assertion triggered rollback.

Need Cloudflare cache-rule/control-plane evidence, targeted invalidation of the
affected public URLs and repeat consistent bare-URL verification. Do not bypass
this gate with query strings or claim origin headers establish edge correctness.
No further activation attempted after this final edge failure. All old roots,
original config and four active services are retained; no migration or data write.
