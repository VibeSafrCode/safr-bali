## Миграция и безопасность

Миграция `f3a9d2c6b810` расширяет только два CHECK, без переписывания данных. Перед production apply обязательны свежий private backup, восстановление в изолированную PostgreSQL-базу и U-D-U на восстановленной копии. Корректность всех строк, схемы, последовательностей, ACL и неизменность цен проверяются внутри сервера; клиентские строки и секреты в этот отчёт не попадают.

Процедура активации проверяет точные SHA кода и immutable static artifacts, целостность всех backup-файлов, неизменность secrets/config/units и единую пару Astro/React. При частичном сбое восстанавливается совместимая пара кода и статики; production downgrade и автоматическое преобразование новых кодов не выполняются. Если новые статусы уже использованы, старая версия кода не возвращается без проверки совместимости. Предыдущая статика и private backup сохраняются.
