## Доступные маршруты API

| Метод и путь | Назначение |
| --- | --- |
| `GET /api/visa-agent/cases/{case_id}` | Чтение назначенного визового дела. |
| `POST /api/visa-agent/submissions` | Регистрация подтверждённой подачи. |
| `POST /api/visa-agent/processes/{process_id}/observations` | Запись наблюдения портала с проверкой области доступа, версии процесса и ключа запроса. |
| `POST /api/visa-agent/cases/{case_id}/issued-document` | Ранее установленный импорт D1 для согласованного дела и файла. |

Cloudflare применяет `bic=false` к четырём сочетаниям метода и пути на `api.safrway.online`. Один внешний контрольный запрос к D1 дошёл до API и получил `401`, `private, no-store` и ответ без cookie. На origin три добавленных маршрута также вернули `401` без токена. Контроль неподдерживаемого метода дал `403`, соседнего пути — `404`, существующего маршрута аренды без токена — `401`.

Эти проверки подтверждают маршрутизацию и отказ в анонимном доступе. Работу с назначенным агентом в production предстоит проверять отдельно от установки. Типизированный черновик анкеты, общий импорт защищённых документов и доставка через исходного бота описаны в [проектном контракте](AGENT_CLIENT_SERVICE_INTAKE_CONTRACT_2026-11-10.md).
