## Известные проблемы baseline

- custom static export не сохраняет RSC payload;
- URL без завершающего `/` получают ошибочный redirect с `:8081`;
- Mini App не получает правильный production API base URL;
- 404-файл отсутствует;
- Open Graph URL указывает на localhost;
- production содержит AppleDouble `._*`;
- metadata большинства страниц не уникальны;
- sitemap, robots, canonical и структурированные данные отсутствуют;
- Telegram Mini App использует `initDataUnsafe` для отображения профиля;
- строгой защиты от повторного использования Telegram initData нет.
